# site_limber

Site institucional da Limber Consultoria.

- **[BENCHMARKING-MEL.md](BENCHMARKING-MEL.md)** — benchmarking de consultorias de monitoramento, avaliação e aprendizagem (MEL/MEAL) no Brasil e no mundo, com implicações para o site.
- **[mockup/index.html](mockup/index.html)** — mockup navegável do site, com design e copy baseados no benchmarking MEL (arquivo único, abra no navegador). Textos e números ilustrativos.
- **[mockup/v1-generico.html](mockup/v1-generico.html)** — primeiro estudo de layout (genérico, pré-benchmarking setorial), mantido para comparação.
